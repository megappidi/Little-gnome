# Little Gnome Widget — MVP

A tiny Android home-screen companion. This is a real App Widget: tapping the gnome updates him in place instead of opening a normal app screen.

## Build without Android Studio
1. Create a GitHub repository and upload the **contents of this folder** (including `.github`).
2. Open the repository's **Actions** tab.
3. Open **Build Little Gnome APK** and choose **Run workflow**. (A push to `main` also starts it.)
4. When the run is green, open it and download the artifact named **LittleGnome-debug-apk**.
5. Unzip it on your Android phone and tap `app-debug.apk` to install. Android may ask you to allow installs from the browser/files app you used.
6. Long-press the home screen → Widgets → **Little Gnome** → place the widget.

The APK is a debug/test build intended for this MVP, not a Play Store release.
